# Hero Wars: Alliance 팀 분석기 (Vercel 배포용 프로토타입)

## 실행
1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm run dev`
4. 배포 전 `npm run build`

## Vercel 배포
- 이 폴더를 GitHub 저장소에 올리고 Vercel에서 해당 저장소를 Import합니다.
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- 별도 환경변수는 필요하지 않습니다.

## 현재 구현
- 영웅 목록 83명 초안, 검색 및 진영/역할 필터
- 아군/상대 각 5인 팀 구성, 프리셋, 브라우저 자동 저장
- 영웅별 성장 설정 입력(레벨, 별, 스킨, 글리프, 일반 유물, 전설 유물, 힘의 불꽃)
- 규칙 기반 시너지/상성 리포트
- 반응형 웹 UI

## 중요: 데이터 및 예측 한계
- 이 빌드는 첫 번째 실행 가능한 골격입니다. 83명 명단과 한글 표기/분류는 반드시 실제 게임 버전과 대조해야 합니다.
- 검증된 능력치와 스킬 계수는 임의로 생성하지 않았습니다. `src/data/heroes.json`에서 `stats: null`, 빈 `skills`, `dataStatus`로 미검증 상태를 표시합니다.
- 현재 결과 숫자는 임시 규칙 기반 우세 지표이며 실제 전투 엔진이나 검증된 승률이 아닙니다. 사용자가 입력한 성장 단계는 임시 상대 점수로만 반영됩니다.
- PDF의 예시에는 규칙 점수로 예상 승률을 환산하는 아이디어가 있지만, 실제 데이터와 대전 로그로 보정하기 전에는 승률로 오인될 수 있어 UI에서는 '아군 우세 지표'로 표기했습니다.
- 게임에서 확인되지 않은 전설 유물 효과/능력치/스킬은 추측으로 채우지 말고, 검증 후 데이터로 추가해야 합니다.

## 주요 파일
- `src/main.jsx`: UI 및 임시 분석 규칙
- `src/data/heroes.json`: 영웅 데이터
- `src/style.css`: 반응형 스타일
- `vercel.json`: SPA 라우팅 설정

## 원본 참고자료
`reference/` 폴더에 기존 HTML 2개와 설계 PDF를 보존했습니다. 현재 프로토타입은 원본 HTML의 모든 기능을 완전히 이식한 버전이 아니라, Vercel 프로젝트 구조와 팀 편성/분석 화면을 먼저 구성한 초기 버전입니다. 다음 개발 단계에서 원본 기능과 대조해 누락된 기능을 이식해야 합니다.
